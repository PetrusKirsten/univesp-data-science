# Modelagem e Inferência Estatística

Espaço para materiais, exercícios, notebooks e pequenos projetos da disciplina
de Modelagem e Inferência Estatística.

## Organização sugerida

```text
modelagem-inferencia-estatistica/
├── README.md
├── semana-01/
│   ├── aula/
│   ├── exercicios/
│   ├── notebooks/
│   └── dados/
└── semana-02/
```

## Sequência da disciplina

1. Regressão linear simples
2. Análise de ajustes
3. Teste de hipótese e previsão da resposta
4. Adequações do modelo e modelos não lineares
5. Métodos gerais de regressão, modelos logístico e polinomial
6. Regressão múltipla, parte 1
7. Regressão múltipla, parte 2
8. Revisão

## Convenções

- `aula/`: materiais originais e anotações diretas da disciplina.
- `notebooks/`: análises reproduzíveis em Python/Jupyter.
- `exercicios/`: resoluções próprias e desafios.
- `dados/`: datasets pequenos ou instruções para obter dados externos.

Quando um exercício virar uma análise maior, incluir um README local com:

- objetivo;
- dados utilizados;
- como executar;
- principais resultados;
- limitações e pressupostos estatísticos.
