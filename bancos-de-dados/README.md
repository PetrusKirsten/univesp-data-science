# Bancos de Dados

Espaço para materiais, modelos, scripts SQL, exercícios e pequenos projetos da
disciplina de Bancos de Dados.

## Organização sugerida

```text
bancos-de-dados/
├── README.md
├── semana-01/
│   ├── aula/
│   ├── exercicios/
│   ├── sql/
│   └── diagramas/
└── semana-02/
```

## Sequência da disciplina

1. Introdução a bancos de dados e modelo entidade-relacionamento
2. Modelo relacional e mapeamento do modelo entidade-relacionamento
3. Sistemas gerenciadores de bancos de dados e normalização
4. SQL, indexação e ferramentas
5. Consultas usando SQL
6. Consultas combinadas, views, Data Warehouse e Data Lake
7. Transações e bancos não relacionais
8. Revisão

## Convenções

- `aula/`: materiais originais da disciplina.
- `diagramas/`: modelos ER, esquemas relacionais e imagens de apoio.
- `sql/`: scripts executáveis, organizados por tema ou exercício.
- `exercicios/`: respostas, análises e documentação das decisões de modelagem.

Para desafios maiores, documentar:

- problema modelado;
- entidades e relacionamentos;
- esquema lógico;
- scripts de criação e carga;
- consultas principais;
- decisões de normalização, índices e restrições.
